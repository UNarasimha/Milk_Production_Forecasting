# Milk_Production_Forecasting
Developed SARIMA and LSTM models to forecast monthly milk production using 27 years of historical data. Applied ADF/KPSS tests and seasonal differencing, achieving 96%+ accuracy and reducing prediction errors by 40%. Generated 12-month forecasts with 95% confidence intervals and built dashboards for production planning.
